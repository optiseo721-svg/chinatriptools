# China Trip Tools

Spanish-first static MVP for `chinatriptools.com`.

## Technical constraints

- Next.js App Router
- Static export with `output: "export"`
- No database
- No API routes
- No Server Actions
- No login
- Browser-only checker logic

## Environment variables

Optional analytics IDs:

```text
NEXT_PUBLIC_GA_MEASUREMENT_ID=
NEXT_PUBLIC_CLARITY_PROJECT_ID=
```
